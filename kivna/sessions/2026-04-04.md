## Key Decisions
- Hooks are opt-in (collaborator-local via settings.local.json), not plugin-level auto-activate
- PostToolUse hook is read-only (reminds, doesn't mutate .active-modes). Mode skill remains sole writer
- .active-modes gets a unified schema as prerequisite to hooks. Each skill owns its own line(s)
- KIF: export both TOON + JSON, import JSON only (no TOON parser needed)
- Exports are repo-grounded first, conversation fills gaps (reverses previous conversation-first approach)
- Lorg ranking uses simple additive score: theme + tech + recency - friction. Cutoff at 15 drops noise
- Stale usage threshold: 30 days (was "never invoked" which hid forgotten skills)
